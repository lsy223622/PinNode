PinNode 快速配置

选择用途模板并生成一次性六位授权码；节点设置和退出策略随授权码下发。

Tailscale 凭据会先由服务端验证，再使用 AES-256-GCM 加密保存；页面和接口不会回显 secret。长期运行推荐使用可自动换取短期 token 的 OAuth client。生产环境仍必须使用 HTTPS，并限制管理端口的访问来源。

快速配置模板

模板会填写核心线路和路由选项，之后仍可继续微调。

Tailscale 管理凭据

选择已加密保存的 OAuth client 或 API access token；生成的授权码会绑定到所选凭据。

OAuth client 适合长期运行，需要 auth_keys、devices:core、devices:routes 权限和 {{MANAGED_DEVICE_TAG}}；普通 API token 最长有效 90 天。前往 Tailscale 创建 OAuth client ↗
